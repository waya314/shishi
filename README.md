# 🎋 SHISHI — 水の音に、時間を預ける

ミニマルな3Dのししおどしと、ブラウザ内で生成される環境音を楽しむリラックスアプリ

## 起動方法

`index.html` を Chrome、Safari、Edge、Firefox などのモダンブラウザで開いてください

- スマートフォン / PC 両対応
- ダウンロード後、**ネット接続なし**で動作
- 外部CDN、ライブラリ、画像、音声素材への依存なし
- 音声は「音をオンにする」をタップすると始まります（ブラウザ仕様）

## 機能

- WebGLによる3Dししおどしアニメーションとスワイプ/ドラッグ操作（WebGLが使えない環境では立体投影によるCanvas描画に切り替え）
- Web Audio APIで合成した水音、風音、鳥/虫の声、竹の音
- 朝 / 夕 / 夜、春 / 夏 / 秋 / 冬、8〜24秒の周期を切り替え
- 各環境音オン/オフ、マスター音量
- 5 / 15 / 25分の休憩タイマー
- 設定の端末内保存（LocalStorage）
- 動画や画像、外部スクリプトを読み込まない軽量な構成

## GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例 `shishi`）を作成
2. このフォルダの `index.html` と `README.md` をリポジトリ直下にアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** で **Deploy from a branch** を選択
5. Branch を `main`、フォルダを `/ (root)` に設定して保存
6. GitHub Pages に表示されるURLを開く（例 `https://<user>.github.io/shishi/`）

## 注意点

- 初回の音声再生にはユーザー操作が必要です
- 3D表示にはWebGL対応ブラウザを推奨しますが、WebGLが利用できない端末ではCanvas 2D表示に自動で切り替わります
- 音声の利用にはWeb Audio API対応ブラウザが必要です
- タイマーは**ページを開いている間**の休憩用です　OSのバックグラウンドでの正確な計時や通知は保証しません
- 季節・時刻切り替えは演出的な表現です
- 本アプリの3D動作は視覚表現を目的としており、厳密な流体シミュレーションではありません
